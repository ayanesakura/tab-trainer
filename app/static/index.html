吉他谱练习器

曲库

上传六线谱图片或 PDF，AI 识别后生成可播放、可循环、带指板显示的练习页面。

还没有设置 API key，识别谱子前请先到 设置 里填写。
识别方式：自动找出每一行六线谱，逐行交给 AI 识读，并检查每个小节的时值是否凑满，凑不满会让 AI 返修一次。一首 30–40 小节的曲子大约 1–3 分钟。

设置

改动会自动保存在本机。

模型
Anthropic API key
只保存在本机 data/config.json（仅本人可读）。也可以改为启动前设置环境变量 ANTHROPIC_API_KEY。
识别模型
Opus 最准；Sonnet 更便宜，准确率低一些。
识别精细度
越高读得越仔细，耗时和费用也越高。
Base URL
一般不用填。走代理或兼容网关时再改。
测试连接
发一个很小的请求，确认 key、模型和地址都能用。
外观
主题
浅色、深色，或跟随系统。
